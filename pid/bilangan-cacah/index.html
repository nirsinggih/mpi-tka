🧮 OPERASI HITUNG BILANGAN CACAH

Konsep Dasar & Urutan Hirarki Operasi (KABATAKU)

Bilangan cacah adalah himpunan bilangan bulat non-negatif {0, 1, 2, 3, 4, ...}.

1. Penjumlahan (+)

a + b = c

Menggabungkan dua kuantitas. Berlaku sifat komutatif (a+b = b+a).

2. Pengurangan (-)

a - b = c

Mengambil sebagian kuantitas dari keseluruhan (a ≥ b).

3. Perkalian (×)

a × b = c

Penjumlahan berulang dari angka b sebanyak a kali.

4. Pembagian (÷)

a ÷ b = c

Pengurangan berulang hingga habis (penyebut b ≠ 0).

Urutan Prioritas Operasi Campuran:

  1. Kerjakan operasi di dalam Tanda Kurung ( ) terlebih dahulu.
  2. Kerjakan Perkalian (×) dan Pembagian (÷) dari kiri ke kanan.
  3. Kerjakan Penjumlahan (+) dan Pengurangan (-) dari kiri ke kanan.

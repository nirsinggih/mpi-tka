2. Urutan Operasi Campuran

Gunakan urutan hirarki berikut saat menyelesaikannya:

  1. Tanda Kurung ( ) - Kerjakan paling awal.
  2. Pangkat / Akar - Kerjakan berikutnya.
  3. Kali (×) & Bagi (÷) - Setara, kerjakan dari kiri ke kanan.
  4. Tambah (+) & Kurang (-) - Setara, kerjakan paling akhir dari kiri ke kanan.
Sifat Matematika

3. Komutatif, Asosiatif, Distributif

• Komutatif: a + b = b + a

• Asosiatif: (a + b) + c = a + (b + c)

• Distributif: a × (b + c) = (a × b) + (a × c)

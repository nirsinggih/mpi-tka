🔢 MPI BARISAN & DERET

Barisan dan Deret Aritmetika SMA

🎯 Tujuan Pembelajaran

Peserta didik mampu menentukan pola barisan aritmetika, mencari suku ke-n, serta menghitung jumlah deret aritmetika.

📚 Konsep Barisan Aritmetika

Barisan aritmetika adalah barisan bilangan yang memiliki selisih tetap antara dua suku berurutan.

2
+
5
+
8
+
11
Beda (d) = 3

📌 Rumus Suku ke-n

aₙ = a₁ + (n - 1)d

Keterangan:

  • aₙ = suku ke-n
  • a₁ = suku pertama
  • n = nomor suku
  • d = beda antar suku

🔍 Contoh Barisan

3, 7, 11, 15, ...

a₁ = 3
d = 4

Suku ke-5:

a₅ = 3 + (5-1)4
a₅ = 19

➕ Konsep Deret Aritmetika

Deret aritmetika adalah penjumlahan dari suku-suku pada barisan aritmetika.

Barisan:
2, 5, 8, 11

Deret:
2 + 5 + 8 + 11

📊 Rumus Jumlah Deret

Sₙ = n/2 (a₁ + aₙ)

atau

Sₙ = n/2 (2a₁+(n-1)d)

🌎 Penerapan Kehidupan

Contoh:

Seseorang menabung:
Hari pertama Rp10.000
Setiap hari bertambah Rp5.000

Jumlah tabungan mengikuti pola deret aritmetika.

🧠 Latihan Interaktif

Barisan:
4, 7, 10, 13, ...

Nilai suku ke-10 adalah...

28
31
34

⭐ Ringkasan

✔ Barisan = susunan bilangan berpola.
✔ Deret = jumlah seluruh suku barisan.
✔ Beda aritmetika selalu tetap.
✔ Suku ke-n menggunakan rumus aₙ.
✔ Jumlah n suku menggunakan rumus Sₙ.

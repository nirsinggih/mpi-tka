Materi: Sistem Bilangan Real

Bilangan Real adalah gabungan dari himpunan bilangan rasional dan irasional. Jenis-jenisnya meliputi:

  • Bilangan Asli (N): Mulai dari 1, 2, 3, 4, ...
  • Bilangan Cacah (W): Mulai dari 0, 1, 2, 3, ...
  • Bilangan Bulat (Z): Negatif, nol, dan positif (..., -2, -1, 0, 1, 2, ...)
  • Bilangan Rasional (Q): Dapat dibentuk pecahan a/b (b ≠ 0). Contoh: 1/2, 0.75
  • Bilangan Irasional: Tidak dapat dibentuk a/b. Contoh: √2, π (pi)

Urutan hierarki dalam operasi bilangan gabungan (KABATAKU / PEMDAS):

  1. Tanda Kurung ( )
  2. Pangkat / Akar
  3. Perkalian (×) dan Pembagian (÷) — dari kiri ke kanan
  4. Penjumlahan (+) dan Pengurangan (−) — dari kiri ke kanan

Contoh Kasus:

2 + 3 × 4 = ?
(Kerjakan perkalian dulu) = 2 + 12 = 14

Sifat-sifat dasar pada operasi penjumlahan dan perkalian bilangan real:

A. Komutatif (Pertukaran) a + b = b + a a × b = b × a Catatan: Tidak berlaku untuk pengurangan dan pembagian.
B. Asosiatif (Pengelompokan) (a + b) + c = a + (b + c) (a × b) × c = a × (b × c)
C. Distributif (Penyebaran) a × (b + c) = (a × b) + (a × c) a × (b - c) = (a × b) - (a × c)

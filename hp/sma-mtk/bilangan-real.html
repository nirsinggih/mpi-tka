Apa itu Bilangan Real?

Bilangan Real ($\mathbb{R}$) memuat semua bilangan yang dapat ditemukan pada garis bilangan. Terbagi menjadi kelompok Rasional dan Irasional.

Pohon Bilangan Real

  • 1. Bilangan Irasional
    Desimal tak berulang & tak berhingga.
    Contoh: $\sqrt{2}, \pi, e$
  • 2. Bilangan Rasional
    Dapat diubah ke pecahan $\frac{a}{b}$ ($b \neq 0$).
    • Pecahan: $\frac{1}{2}, \frac{3}{4}, 0.75$
    • Bulat ($\mathbb{Z}$): $\{\dots, -2, -1, 0, 1, 2, \dots\}$
  • 3. Bilangan Cacah & Asli
    Cacah: $\{0, 1, 2, \dots\}$
    Asli ($\mathbb{N}$): $\{1, 2, 3, \dots\}$

Urutan Operasi (PEMDAS)

Saat menyelesaikan kombinasi operasi hitung, ikuti urutan prioritas berikut:

1. ( ) Kurung
2. x² / √ Eksponen & Akar
3. × / ÷ Perkalian & Pembagian
4. + / - Penjumlahan & Pengurangan

Aturan Tanda Perkalian

  • $(+) \times (+) = \mathbf{(+)}$  |  $(-) \times (-) = \mathbf{(+)}$
  • $(+) \times (-) = \mathbf{(-)}$  |  $(-) \times (+) = \mathbf{(-)}$

1. Sifat Komutatif

Posisi angka boleh ditukar (berlaku untuk $+$ dan $\times$).

$a + b = b + a$
$a \times b = b \times a$

Contoh: $4 + 7 = 7 + 4 = 11$

2. Sifat Asosiatif

Pengelompokan urutan hitung boleh diubah.

$(a + b) + c = a + (b + c)$
$(a \times b) \times c = a \times (b \times c)$

Contoh: $(2 + 3) + 5 = 2 + (3 + 5) = 10$

3. Sifat Distributif

Operasi perkalian disebarkan ke dalam penjumlahan/pengurangan.

$a \times (b + c) = (a \times b) + (a \times c)$
$a \times (b - c) = (a \times b) - (a \times c)$

Contoh: $3 \times (10 + 2) = (3 \times 10) + (3 \times 2) = 36$

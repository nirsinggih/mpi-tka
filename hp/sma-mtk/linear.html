📊 MPI PROGRAM LINEAR

Optimasi Masalah Matematika SMA

🎯 Tujuan Pembelajaran

Peserta didik mampu membuat model matematika, menentukan daerah penyelesaian, dan mencari nilai optimum pada masalah program linear.

📚 Konsep Dasar

Program linear adalah metode matematika untuk menentukan nilai maksimum atau minimum suatu fungsi dengan batasan tertentu.

Fungsi Objektif: Z = ax + by

Keterangan:
x,y = variabel keputusan
a,b = koefisien
Z = nilai yang ingin dioptimalkan

🔎 Unsur Program Linear

1. Variabel Keputusan

Besaran yang belum diketahui dan akan dicari nilainya.

2. Fungsi Tujuan

Fungsi yang akan dimaksimumkan atau diminimumkan.

Contoh:
Maksimumkan:
Z = 5x + 3y

3. Kendala

Batasan yang harus dipenuhi.

2x + y ≤ 10
x ≥ 0
y ≥ 0

📝 Langkah Penyelesaian

1
Buat variabel keputusan
2
Susun model matematika
3
Gambar daerah penyelesaian
4
Tentukan titik pojok
5
Hitung nilai maksimum/minimum

🏭 Simulasi Masalah

Sebuah toko membuat:

x = jumlah meja
y = jumlah kursi

Keuntungan:
Meja = Rp50.000
Kursi = Rp30.000

Fungsi tujuan:
Z = 50000x + 30000y

Tujuan: Mencari kombinasi meja dan kursi agar keuntungan maksimum.

📈 Daerah Penyelesaian

Pada program linear dua variabel, solusi berada pada daerah yang memenuhi semua pertidaksamaan.

Daerah yang memenuhi semua kendala disebut:

Daerah feasible

Nilai optimum biasanya terdapat pada titik pojok daerah penyelesaian.
